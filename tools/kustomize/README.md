# Kustomize Pod 模板示例

本目录演示如何使用 [Kustomize](https://kustomize.io/) 对 Kubernetes Pod 资源进行定制化管理。

## 目录结构

```
tools/kustomize/
├── README.md           # 本说明文件
├── kustomization.yaml  # kustomize 配置文件（定制规则）
└── pod.yaml            # 基础 Pod 资源定义
```

## 文件说明

### pod.yaml

基础 Pod 资源，包含：

- nginx 容器（镜像 `nginx:1.25`）
- 端口暴露（80/TCP）
- 资源请求与限制（CPU 100m-200m，内存 128Mi-256Mi）

### kustomization.yaml

Kustomize 配置文件，定义了以下定制规则：

| 字段               | 作用                                   | 示例效果                  |
| ------------------ | -------------------------------------- | ------------------------- |
| `namePrefix`       | 为所有资源名添加前缀                   | `my-pod` → `dev-my-pod`   |
| `commonLabels`     | 批量添加公共标签                       | 附加 `env: dev` 等        |
| `commonAnnotations`| 批量添加公共注解                       | 附加 `note` 注解          |
| `resources`        | 声明引用的资源文件                     | 引用 `pod.yaml`           |
| `images`           | 镜像替换                               | `nginx:1.25` → `nginx:1.27` |

## 使用方式

### 预览生成的最终 YAML

```bash
kubectl kustomize .
```

或使用 kustomize 原生命令：

```bash
kustomize build .
```

### 直接应用到集群

```bash
kubectl apply -k .
```

### 查看 Pod 状态

```bash
kubectl get pods -l app=my-pod
```

## 预期输出

执行 `kubectl kustomize .` 后，生成的最终 YAML 如下：

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: dev-my-pod          # namePrefix 生效
  labels:
    app: my-pod
    env: dev                 # commonLabels 生效
    managed-by: kustomize
  annotations:
    note: generated by kustomize   # commonAnnotations 生效
spec:
  containers:
  - name: nginx
    image: nginx:1.27        # images 替换生效
    ports:
    - containerPort: 80
      protocol: TCP
    resources:
      requests:
        cpu: 100m
        memory: 128Mi
      limits:
        cpu: 200m
        memory: 256Mi
```

## 扩展建议

- **多环境管理**：可创建 `overlays/dev`、`overlays/prod` 目录，分别放置不同环境的定制配置
- **ConfigMap/Secret 生成**：使用 `configMapGenerator` 从文件或字面值生成配置
- **Patch 修改**：使用 `patches` 字段对资源字段进行精细修改
